## ❓ Section 9 — FAQs

### Section Header
**Eyebrow:** `FAQS`
**Headline:**
```
Got Questions?
```

---

**Q: Is Project OS really free?**
```
Yes. 100% free, open-source, and MIT-licensed. No freemium upsells, no premium tiers, no hidden costs. Ever.
```

**Q: Does it work on browsers other than Chrome?**
```
It works on any Chromium-based browser — Chrome, Brave, Edge, Arc, Vivaldi, Opera. Firefox support is on the roadmap.
```

**Q: Will it slow down my browser?**
```
No. Project OS loads instantly (0ms new-tab latency) because everything runs locally. There are no external API calls on startup.
```

**Q: Where is my data stored?**
```
Entirely on your device using chrome.storage.local. We have zero access to your data — no servers, no databases, no accounts.
```

**Q: Can I use my own wallpapers?**
```
Absolutely. Upload any high-res image or animated video (.mp4, .webm). You can also adjust blur, dark overlay, and sizing.
```

**Q: Can I sync my data across devices?**
```
Not yet natively, but you can use the JSON Backup & Restore feature to manually export your setup and import it on another machine.
```

**Q: How do I update the extension?**
```
Pull the latest changes from GitHub, run npm run build, and click the reload icon on chrome://extensions. That's it.
```

**Q: Can I contribute?**
```
Yes! We welcome PRs, bug reports, feature requests, and theme contributions. Check the GitHub repo for contribution guidelines.
```

## 🎨 Design Notes (for Figma reference)

### Color Palette (from Figma screenshot)
| Token | Value | Usage |
|:---|:---|:---|
| **Background** | `#0A0A0A` / `#111111` | Page background, sections |
| **Surface** | `#1A1A1A` / `#1E1E1E` | Cards, containers |
| **Accent Warm** | `#F59E0B` / `#D97706` | Buttons, highlights, badges |
| **Accent Glow** | `#FBBF24` | Hover states, active elements |
| **Text Primary** | `#FFFFFF` | Headlines, body text |
| **Text Secondary** | `#9CA3AF` / `#6B7280` | Supporting copy, labels |
| **Border** | `rgba(255,255,255,0.08)` | Card borders, dividers |

### Typography
| Element | Font | Weight | Size (approx) |
|:---|:---|:---|:---|
| **Nav Links** | Gilroy / Inter | Medium (500) | 14px |
| **Hero Headline** | Gilroy | Bold (700) | 56–72px |
| **Hero "Missing"** | Heathergreen | Regular | 56–72px (script) |
| **Subheadline** | Gilroy / Inter | Regular (400) | 18–20px |
| **Section Eyebrow** | Gilroy / Inter | Bold (700) | 12–14px (uppercase, tracked) |
| **Section Headline** | Gilroy | Bold (700) | 40–48px |
| **Card Title** | Gilroy | Bold (700) | 20–24px |
| **Card Description** | Inter | Regular (400) | 15–16px |
| **Body Text** | Inter | Regular (400) | 16px |
| **Button Text** | Gilroy | Bold (700) | 14px (uppercase, tracked) |

### Visual Style
- **Overall Mood:** Dark, premium, warm-toned — similar to a high-end dev tool or gaming product page.
- **Card Style:** Subtle dark surface (`#1A1A1A`) with `1px` border at `rgba(255,255,255,0.06)`, rounded corners (`12–16px`).
- **Glow Effects:** Warm amber glow behind hero CTAs and key interactive elements.
- **Gradients:** Subtle top-down dark gradients on section backgrounds to create depth separation.
- **Imagery:** Product screenshots should have a soft drop shadow and sit inside stylized browser chrome frames.
- **Spacing:** Generous whitespace — 120px+ between major sections, 40–60px internal section padding.
- **Animations (for development):** Scroll-triggered fade-in/slide-up on feature cards, parallax on hero mockup, smooth hover lifts on cards.
